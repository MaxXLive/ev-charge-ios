# fastlane: App Store Connect automation

Automates building, screenshots, metadata (10 languages) and submission to App
Store Connect. Run all commands from the `evcharge/` directory (next to
`evcharge.xcodeproj`).

> `fastlane/README.md` is auto-generated by fastlane on every run; do not edit
> it. This file (`SETUP.md`) is the hand-written setup guide.

## One-time setup

### 1. App Store Connect API key (DONE)

Key `DSN7P6CP9L` is in `fastlane/AuthKey_DSN7P6CP9L.p8`, config in `fastlane/.env`
(both gitignored). `fastlane verify` confirms auth.

To rotate: ASC → Users and Access → Integrations → App Store Connect API, create
a key with **App Manager** role, download the `.p8`, update `fastlane/.env`.

### 2. Ruby deps (recommended)

```bash
cd evcharge
bundle install            # installs the fastlane version pinned in Gemfile
# then prefix commands with `bundle exec`, e.g. `bundle exec fastlane release`
```

### 3. UI test target for screenshots

`fastlane screenshots` needs a UI test target. It does not exist yet, so add it
once in Xcode (≈30 s):

1. Xcode → **File → New → Target… → UI Testing Bundle**, name it `evchargeUITests`,
   Target to be Tested: `evcharge`.
2. Delete the auto-generated `.swift` file Xcode adds.
3. Add the two existing files to the new target: `evchargeUITests/SnapshotHelper.swift`
   and `evchargeUITests/evchargeUITests.swift`.
4. Ensure a **shared scheme** named `evchargeUITests` exists (Product → Scheme →
   Manage Schemes → check "Shared").

Tune the taps in `evchargeUITests/evchargeUITests.swift` if the UI changes. Accessibility identifiers on the SwiftUI pins/buttons keep taps stable. The
test already dismisses the system location-permission alert (springboard button
index 1 = "Allow While Using App", language-independent).

## Screenshots & device frames

`fastlane screenshots` runs a 3-step pipeline:

1. **snapshot** captures raw screenshots on **iPhone 17 Pro** (1206×2622, 6.3").
2. **frameit** wraps each in the official Apple iPhone 17 Pro device frame
   (auto-downloaded to `~/.fastlane/frameit-frames`). Needs ImageMagick
   (`brew install imagemagick`).
3. **pad_framed.sh** pads each `*_framed.png` onto a white canvas to exactly
   **1290×2796** (App Store 6.9" slot). frameit's native output size is not an
   accepted ASC dimension, so this step is required.

`deliver` auto-detects `*_framed.png` and uploads only those (skips the raw
ones). To change frame device or background colour, edit `Snapfile` (devices)
and the `pad_framed.sh` call in the `screenshots` lane (target size / bg).

> The raw 1206×2622 (6.3") shots are also valid ASC sizes. To upload unframed, point deliver at the non-`_framed` files.

## Lanes

| Command | Does |
|---|---|
| `fastlane verify` | Check API key auth + app record exists (no upload) |
| `fastlane build` | Signed Release `.ipa` into `build/` |
| `fastlane screenshots` | Capture localized screenshots (all 10 languages) → `fastlane/screenshots/` |
| `fastlane beta` | Bump build number, build, upload to TestFlight |
| `fastlane metadata` | Upload text + screenshots only, no binary |
| `fastlane release` | Build, upload binary + metadata + screenshots, submit for review |

## Languages

Store metadata in `metadata/<locale>/`. 10 locales:
`cs, de-DE, en-US, fr-FR, it, nl-NL, no, pt-PT, ro, sv`.

> The app ships an 11th UI language (Estonian, `et`) but **App Store Connect has
> no Estonian storefront localization**, so there is no `et` metadata folder.

Edit `release_notes.txt` in each locale before every `release`/`metadata` run.
it currently says "Initial release.".

## Version

The version comes from `MARKETING_VERSION` / `CURRENT_PROJECT_VERSION` in
`project.pbxproj` (single source of truth). `beta` auto-increments the build
number; bump `MARKETING_VERSION` per the rules in the root `CLAUDE.md`.
